# Roadmap

## Fase 1 - MVP local

- Estructura base del proyecto.
- Base de datos MariaDB local con Docker.
- Productos demo.
- Tres carteras virtuales de 300.000 EUR.
- Simulacion determinista con renta mensual.
- Dashboard HTML basico.
- Exportacion Excel demo.

## Fase 2 - Datos manuales y trazabilidad

- Alta/edicion de productos desde la web.
- Carga manual de precios.
- Importacion CSV/Excel.
- Historico por producto.
- Evolucion real por cartera.

## Fase 3 - Fuentes oficiales y legales

- Series de inflacion.
- Tipos oficiales BCE.
- Series Banco de Espana.
- Catalogo/validacion CNMV cuando aplique.

## Fase 4 - Despliegue gratuito

- Backend en Render Free.
- BBDD MySQL compatible en TiDB Cloud Starter o alternativa gratuita.
- Variables de entorno y backup.

## Fase 5 - Seguridad

- Login privado.
- Roles basicos.
- Auditoria de cambios.
