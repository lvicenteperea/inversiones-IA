# Politica de inversion simulada

Este documento describe la politica inicial para simulacion. No es asesoramiento financiero.

## Objetivo

Simular una estrategia conservadora a largo plazo con dos objetivos:

1. Generar una renta mensual/anual prudente.
2. Mantener crecimiento suficiente para reducir la perdida de poder adquisitivo por inflacion.

## Capital inicial de referencia

- Capital virtual: 300.000 EUR.
- Renta mensual simulada inicial: 650 EUR.

## Carteras demo

### Muy conservadora

- 30% liquidez/monetario.
- 45% renta fija EUR corto plazo.
- 20% mixta conservadora.
- 5% renta variable global.

### Conservadora equilibrada

- 20% liquidez/monetario.
- 35% renta fija EUR corto plazo.
- 35% mixta conservadora.
- 10% renta variable global.

### Conservadora crecimiento

- 15% liquidez/monetario.
- 30% renta fija EUR corto plazo.
- 35% mixta conservadora.
- 20% renta variable global.

## Reglas iniciales

- Evitar productos complejos o no entendidos.
- Evitar exposicion excesiva a divisa distinta de EUR.
- Evitar bonos individuales muy largos en la parte conservadora.
- Revisar resultados mensualmente, no a diario.
- Registrar cada cambio de criterio.
